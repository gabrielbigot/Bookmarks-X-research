Modèle de recherche sémantique

Changer de modèle recalcule les vecteurs de tous les tweets (long : compte plus d'une heure pour 30 000 tweets). Les vecteurs de l'autre modèle sont conservés : revenir en arrière est immédiat. EmbeddingGemma 2 place texte et images dans le même espace (active « Recherche dans les images » ci-dessous pour chercher dans les images avec n'importe quelle langue).

Modèle de décision — Jev (facultatif)

Un modèle de décision ne rédige pas : il classe et note, très vite et pour presque rien. Ici : comprendre le tri / la période / le type de contenu d'une requête, et reclasser les 20 meilleurs résultats (une note par tweet). Appelé via l'API Decisions d'OpenRouter (modèle typesafe/jev-1.13).

IA (facultatif)

Active les questions-réponses, le résumé, la compréhension des requêtes et le reclassement. Fonctionne avec toute API compatible OpenAI. Rien n'est envoyé tant que ce n'est pas configuré ; la clé reste sur cet appareil.

Performances & mémoire

Le calcul des embeddings sur le GPU est rapide mais peut consommer beaucoup de mémoire sur de longs traitements. Le modèle est libéré automatiquement toutes les ~1 000 tweets et après 10 min d'inactivité.
